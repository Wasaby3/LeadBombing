# Правила интерфейса LeadBombing

Обязательный свод для всего, что появляется в `leadbombing/web/static/app/`: новые экраны, окна, кнопки, тексты.
Что из чего собирать (токены, классы, JS-помощники) — в [DESIGN.md](../DESIGN.md); как работать над новой фичей —
§8 ниже. Основа: Vercel Web Interface Guidelines и Impeccable (critique, clarify, audit, polish), разбор —
`docs/ux/DIAGNOSTICS.md`, решения и итог — `docs/UX-AUDIT.md`.

## 1. Кнопки: уровень = роль

| Уровень | Класс | Когда | Сколько |
|---|---|---|---|
| Primary | `.btn.primary` | главное действие области | одна на область |
| Secondary | `.btn` | обычные действия рядом с главным | ≤ 3 видимых, остальное в «Ещё ⋯» |
| Ghost | `.btn.ghost` | третьестепенное: «Отмена», «Открыть в 2ГИС», переходы | — |
| Danger | `.btn.danger` (кнопка в диалоге подтверждения), `.btn.danger-ghost` (кнопка, открывающая подтверждение) | только необратимое: удалить лид, очистить поиск | — |

- **Область** — шапка страницы, панель поиска, заголовок результатов, карточка лида, каждый диалог.
  В диалоге primary — кнопка, называющая действие; в панели поиска — «Найти лиды».
- «Остановить» — не danger: остановленный поиск можно продолжить. Это secondary с иконкой ■.
- Цвет = роль. Акцентный — только primary, выбранное и ссылки. Красный — только danger и ошибки.
- Цвета WhatsApp / Telegram / ВКонтакте (`--wa`, `--tg`, `--vk`) — только метка канала (точка, бейдж). Кнопки этими
  цветами не красятся.
- Неактивная кнопка не прячет причину только в `title` (на телефоне его не видно): причина видна текстом рядом, или
  кнопки нет.

## 2. Окна

| Тип | Для чего | Здесь |
|---|---|---|
| Панель справа | смотреть или править, не теряя список | карточка лида (поиск и «Лиды») |
| Центральный диалог | короткое решение или подтверждение | выгрузка, сохранение в папку, очистка поиска, удаление лида |
| Toast | ненавязчивый итог действия | «Лиды сохранены», «Сообщение скопировано», «Поиск завершён» |
| Ошибка у поля | неверный ввод | запрос, города, ссылка на демо, путь выгрузки, вход |
| Баннер над результатами | ошибка процесса | капча 2ГИС, нет связи с сервером |

Все окна: `Esc` закрывает верхнее окно; при открытии фокус переходит внутрь (первое поле или главная кнопка), `Tab`
не выходит наружу, при закрытии фокус возвращается на то, что окно открыло. `role="dialog"` / `alertdialog`,
`aria-modal`, `aria-labelledby` на заголовок. Toast — `role="status"`, ошибки — `role="alert"`.
Прокрутка внутри панели и диалога — `overscroll-behavior: contain`.

## 3. Зоны экрана

- **Шапка приложения** (боковое меню на ПК, нижняя панель на телефоне): навигация, переключатель темы, профиль.
  Больше ничего.
- **Шапка страницы**: заголовок (`h1`) и действия над всей страницей.
- **Панель поиска**: сфера → запрос → города → фирм на город → «Найти лиды» в конце строки. Кнопка запуска сама
  становится «Остановить»; статус процесса — рядом с ней.
- **Заголовок результатов**: счётчик и отсеянные, фильтр по таблице, массовые действия («Сохранить лиды»,
  «Очистить поиск»), выгрузка («Выгрузить» — primary этой области).
- Статус поиска и «Остановить» — не в шапке.
- На ширине 375 ничего не выходит за экран: строка действий переносится, вторичное уходит в «Ещё ⋯».

## 4. Тексты

- Глагол + объект: «Найти лиды», «Выгрузить лиды», «Сохранить комментарий». До 3 слов.
- Одно действие — одно слово везде:

| Понятие | Слово | Не использовать |
|---|---|---|
| записать лиды в папку на диске | **Выгрузить** | «Выгрузить всё / все / папку» как разные кнопки |
| положить лиды в папку кабинета | **Сохранить лиды** | «Сохранить» без объекта |
| папка в кабинете | **папка** | — |
| папка на диске | **папка выгрузки** | просто «папка» |
| вернуть таблицу и форму к началу | **Очистить поиск** | «Очистить» без объекта |
| массовая работа над лидами папки (сейчас ссылки на демо) | **Проработать лиды** (на телефоне «Проработать») | «Оценить», «Обработать» |
| прекратить поиск | **Остановить** | «Пауза», «Стоп» |
| копировать в буфер | **Копировать** + объект | «копировать» строчными |
| город поиска | **Города** | «Регионы» |
| канал, куда писать | **Канал** | «Писать сюда» |

- В диалоге кнопка называет действие: «Удалить лид», «Очистить поиск», «Выгрузить 19 лидов». Не «ОК», не «Да».
- Первая буква заглавная, остальные строчные. Правило Vercel про Title Case не применяем: интерфейс на русском.
- Числа со словами склоняются: «1 лид», «2 лида», «5 лидов».
- Загрузка заканчивается на «…»: «Сохраняем…». Плейсхолдер — пример с «…».
- Ошибка говорит, что не так и что сделать.

## 5. Иконки

- Набор Lucide: `stroke-width: 2`, 16–18 px, `stroke: currentColor`. Хранятся локально: спрайт
  `static/app/vendor/icons.svg` только из нужных иконок (`<use href="…#name">`), без CDN; спрайт в кэше `sw.js`.
- Главные действия — иконка и текст. Только иконка — для общепринятого (закрыть, тема, ещё ⋯, свернуть разделы,
  выйти в боковом меню),
  и тогда обязательно `aria-label` и `title`.
- Одно действие = одна иконка во всём приложении:

| Действие | Иконка Lucide |
|---|---|
| Найти лиды, Продолжить поиск | `play` |
| Остановить | `square` |
| Выгрузить | `download` |
| Сохранить лиды | `folder-plus` |
| Проработать лиды | `wand-sparkles` |
| Очистить поиск | `eraser` |
| Удалить лид | `trash-2` |
| Открыть папку выгрузки, Выбрать папку | `folder-open` |
| Написать | `send` |
| Копировать … | `copy` |
| Открыть в 2ГИС, Открыть демо | `external-link` |
| Закрыть | `x` |
| Свернуть / развернуть разделы | `chevrons-down-up` / `chevrons-up-down` |
| Тема | `sun` / `moon` |
| Ещё | `ellipsis` |
| Выйти | `log-out` |
| Меню: Поиск лидов, Лиды, Настройки, Документация | `search`, `users`, `sliders-horizontal`, `book-open` |

- Иконка меняется вместе с состоянием: ▶ `play` «Найти лиды» → ■ `square` «Остановить» (поиск останавливается, а не
  приостанавливается — не пауза).
- Текстовые значки в кнопках (✕, ↗) заменяются иконками; декоративные SVG — `aria-hidden="true"`.

## 6. Тема

- В шапке приложения — кнопка-иконка: в светлой теме луна («Включить тёмную тему»), в тёмной — солнце.
- В «Настройках» три варианта: «Светлая», «Тёмная», «Как в системе». Состояние общее (`lb.theme`): кнопка в шапке
  ставит явную тему, «Как в системе» сбрасывает выбор, обе показывают одно и то же.
- Контраст текста ≥ 4,5:1 в обеих темах. Под белым текстом — только `--accent-fill` и `--danger-fill`.

## 7. Состояния

Поиск, «Лиды», карточка лида и настройки показывают загрузку («…»), пустое состояние (что это значит + следующее
действие кнопкой) и ошибку (что случилось + как исправить). У поиска ещё: идёт, завершён, остановлен, прерван.
Анимации уважают `prefers-reduced-motion`.

## 8. Новая фича: как делать

1. **Место.** Определить зону (§3) и тип окна (§2): действие над всей таблицей — в заголовок результатов или «Ещё ⋯»;
   действие над одним лидом — в карточку; процесс — статус в `.run-bar`; итог — toast; ошибка ввода — у поля.
2. **Сборка.** Только классы и токены из [DESIGN.md](../DESIGN.md). Нужен вариант — модификатор существующего класса;
   новый токен — во все три блока тем; новая иконка — символ Lucide в `vendor/icons.svg` + поднять `CACHE` в `sw.js`.
3. **Уровень кнопки** по §1: не больше одной primary в области; «Отмена» — ghost; danger — только необратимое.
4. **Текст** по §4: глагол + объект, до 3 слов, слово из словаря; новое понятие — сначала добавить в словарь.
   Подпись в диалоге называет действие. Склонение — `plural()`, даты — `formatDate()`.
5. **Доступность:** у иконки-кнопки `aria-label` и `title`; у поля подпись и `name`; ошибка — `role="alert"` +
   `aria-describedby`; новое окно — в `WINDOWS` (фокус внутрь, Tab внутри, возврат), Esc закрывает; radiogroup —
   `radioKeys`; движение — с вариантом для `prefers-reduced-motion`.
6. **Состояния:** загрузка, пусто (со следующим действием), ошибка (с исправлением), неактивное (причина видна).
7. **Проверка перед коммитом:**
   - скриншоты 1440 и 375, светлая и тёмная тема (Playwright) — в `docs/ux/after/`; на 375 нет горизонтальной
     прокрутки (`document.documentElement.scrollWidth === 375`);
   - `/web-design-guidelines` по изменённым файлам `app/` — без P0–P1;
   - Impeccable `audit` (детектор: `.claude/skills/impeccable/scripts/impeccable detect --json …/index.html`) — без
     новых находок; для нового экрана — Impeccable `critique`, в конце — `polish`;
   - встроенная «Документация» и `docs/LOGIC.md` описывают новое поведение одинаково;
   - `pytest --ignore=tests/test_parser.py` зелёный.
8. **Коммит** — один экран или одна фича за коммит; если правило меняется, правится и этот файл.
