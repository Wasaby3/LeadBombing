# История изменений

## [1.0.0] - 2026-11-17

Первый выпуск LeadBombing.

### Добавлено
- Веб-приложение на http://localhost:8666 (`leadbombing`): поиск лидов по сферам, живой прогресс, выгрузка в папку.
- Сферы: «Бани и сауны» (Москва), «Автосервисы», «Салоны красоты», «Стоматологии» и свободный поиск по любому запросу.
- Несколько городов за один запуск и лимит фирм на город.
- Выгрузка лидов: `leads.json`, `outreach.csv`, `tenants/<slug>/business.json` и фото; слияние с существующей
  папкой без перезаписи ручных полей «Статус» и «Руководитель».
- Вход и личный кабинет на локальном Supabase: настройки, история запусков, сохранённые лиды и папки.
- Классический режим `/classic` для обычного парсинга с фильтрами и экспортом.
- CLI `leadbombing-cli` для выгрузки в CSV / XLSX / JSON / HTML / leads, фильтры `--filters.*`
  и чистый режим CSV `--writer.csv.clean`.
- Капча или блокировка 2ГИС останавливает поиск; уже найденное сохраняется.
